# Medexos Surgical

WordPress theme with a full-width Elementor page template and a configurable WhatsApp enquiry button.

The installable theme source is in `medexos-surgical/`. On staging, activate the theme, install Elementor, and select **Medexos Full Width** for pages you want to build in Elementor. Set the WhatsApp number in **Appearance → Customize → Medexos Contact**.

The built-in homepage uses an illustration in the B2B section until the replacement portrait is available. Catalogue documents are managed separately from the theme.
